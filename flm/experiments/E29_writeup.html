Fuzzy language model · engineering log · experiment E29

Word-level consequents make the interpretable model the best model

Giving each fuzzy rule a word distribution instead of a scalar takes perplexity from 355.5 to 219.9 — past a bigram and a tuned trigram on the same corpus. The interpretable architecture is now also the accurate one.

1M-token narrative corpus · sentence-level 80/20 split · 1,000 held-out positions, each with ≥32 tokens of left context · every model scored on the same positions and candidate set

What changed

For ten experiments this model could say “a noun follows” and never “which noun”. A zero-order Takagi–Sugeno rule carries a scalar consequent, so IF prev1:DETERMINER AND cand:OPEN_NOUN THEN 0.265 assigns the same 0.265 to every noun in the vocabulary. Six hypotheses about the quality ceiling were refuted in a row — corpus scale, out-of-vocabulary quality, rule budget, context width, false-discovery control, relational context — because none of them touched the shape of the consequent.

The fix replaces the scalar with a distribution over words:

p(w | ctx) = Σr ωr(ctx) · pr(w) / Σr ωr(ctx)

where ωr is a rule's context-side firing strength and pr(w) is the word distribution observed when it fires. Each rule becomes a soft, named, overlapping context class with its own next-word distribution — a fuzzy class-based language model, the graded analogue of class-based n-grams (Brown, Della Pietra, deSouza, Lai & Mercer, 1992), where classes were a hard clustering.

Two structural consequences followed. The noise-contrastive inversion disappears, since pr(w) are already distributions — no double-counting of the unigram prior. And the constraint that every rule must touch the candidate inverts: correct for scalar consequents, because a context-only rule shifts all candidates equally and cannot change a ranking; wrong here, because a context-only rule is a class.

The result E29.3worked

The earlier attempt estimated these distributions from 20,000 positions and looked like a clear failure. Estimating a distribution per class needs far more data than estimating a scalar, and the curve only flattened when the corpus ran out.

The honesty check

The gain is measured against a bigram, so it could have evaporated against a stronger partner. It does not: 204.5 mixed with a bigram, 201.7 mixed with a trigram — and in the three-way mixture the bigram's optimal weight is exactly zero. This was the test that could have deflated the headline, and it did the opposite.

Two hypotheses that failed

E29.1 Held-out class selection failed

Class selection scores candidates by information gain measured on the same rows that estimated them, which rewards low entropy and so prefers classes that look sharp by accident. Scoring on held-out rows should have removed that bias. It did not help, and at low smoothing it destroyed the mixture contribution entirely (λ → 0).

My own design was confounded. Holding out 30% of rows also makes the minimum-mass floor about 3.3× stricter, so class count fell 1,670 → 397 and the experiment moved criterion and threshold together. The clean version rescales the floor.

E29.2 Hierarchical parent backoff failed

Each class smooths toward the unigram, which throws away the hierarchy the miner just built — a conjunction like prev2:=the AND prev1:QUANTIFIER should fall back on prev1:QUANTIFIER. That is standard practice (Katz backoff, Kneser–Ney), and it made things worse everywhere.

The reason is structural and worth keeping. In a mixture of experts the parents are already in the mixture. Backoff exists for a model that consults one distribution and needs a fallback; here averaging over all classes already performs the backoff, so making a child resemble its parent adds redundancy and dilutes the one thing the conjunction contributed. Right idiom, wrong architecture.

Size E29.5

Learned parameters are one word distribution per class, kept sparse at its top 20 words. Quality keeps improving with class count, so unlike the zero-order system the smallest and best configurations now differ.

Generation E29.6metric rebuilt

Every claim about generation so far had been eyeballed. My first metric — the share of adjacent category pairs the corpus produces — scored real text, the fuzzy model, and a bigram all at 100.0%: with ~17 categories nearly every pair occurs somewhere, so it discriminated nothing. Replaced with category-sequence perplexity under a category bigram, which is graded and cannot be saturated.

What the model is made of

This is the part the project was actually about. Each class is a named conjunction with a readable word distribution and a measured information gain in nats — not a post-hoc explanation of a dense model, but the model itself.

IF prev2:=he AND prev1:=did → not(0.701) so(0.045) it(0.033) 4.37 nats IF prev2:PRONOUN AND prev1:=did → not(0.674) it(0.032) so(0.029) 4.03 nats IF prev1:=did → not(0.561) you(0.053) it(0.033) 3.42 nats IF prev1:=little → jackal(0.035) boy(0.033) girl(0.025) 0.52 nats IF prev2:=the → of(0.190) and(0.074) was(0.026) 0.70 nats

That little class is a bug resolving itself with data. At 20,000 positions it predicted jackal at 0.105 — top of the distribution after “the little” — off a handful of observations, because information gain rewards low entropy and so favours classes that look sharp by accident. At full data jackal sits at 0.035 among boy and girl, where it belongs: Bryant's stories genuinely do contain “the little jackal” often.

Where it stands

  • Beats n-grams standalone, 219.9 against 284.4, on the same corpus, split, and held-out positions — the first configuration in this project to win outright rather than contribute to a mixture.
  • Interpretability is not being paid for with quality. The named-class model is now also the best-performing one.
  • Trains on a laptop. About 16 minutes on one CPU core at full data, three minutes at 300,000 positions, no GPU. 80 tests pass.
  • Global coherence is the open problem. Samples are locally plausible and globally incoherent, and a two-token antecedent cannot carry discourse state.
  • The class cap was still binding. Quality was improving at 3,000 classes, and order-3 context classes are untested.
Not tested here, and worth naming: GPT-2 (unreachable in this environment, and a 40GB-vs-1M-token comparison measures the data gap rather than the method), any neural-embedding comparison, and the sentiment-analysis arm of the project.
